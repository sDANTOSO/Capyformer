# Capyformer


## Background
In my game you play as a capybara in a forest next to a snowy mountain. This game was made for Haven Jumpstart
p.s sign up for Haven Wellington:
[haven signup](https://forms.hackclub.com/haven-signup?r=168&ref=short-link-referral)
## How I made my game
My game was made with godot and the assets were made with asesprite. I just used a character body 2d and a bunch of world assets to make a platformer world the capybara could explore

## How to play my game 
a = left
d= right
space = jump

My game can be played on itch
https://l0ading-studi0s.itch.io/capyformer
